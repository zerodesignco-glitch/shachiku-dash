# Privacy

- **すべてローカルで処理します。** ネットワーク通信、ログイン、telemetry、外部のAI・翻訳・OCRサービスは使いません。OCRにはmacOS標準のVisionをオンデバイスで使います。
- **入力は読むだけです。** 画像、manifest、文言を変更しません。終了時にhashを再計算し、変わっていれば終了コード2で知らせます。
- **出力について**：`--out` で指定したdirectoryに、`report.json`、`index.html`、`images/`（入力画像をhash名でコピーしたもの）を書き出します。レポートには**未公開のコピー（文言）や画像が含まれます**。共有するときは、未公開情報として扱ってください。自動でアップロードすることはありません。
- **中間ファイル**：一時ファイルは作りません（画像はメモリ上でヘッダを読み、OCRはOSのAPIに直接渡します）。
- **HTMLレポート**：外部のfont、CDN、scriptを読み込みません。CSPで `default-src 'none'` を指定しています。文言とファイル名はすべてescapeします。
- **fixture**：`Fixtures/` の画像と文言はすべて合成したものです。実際の製品のスクショや顧客データは含みません。
- **commitしないもの**：生成したレポート、実案件の素材、秘密情報。`.gitignore` で `.build/` と `/report/` を除外しています。実案件の入力は、repositoryの外に置いてください。
